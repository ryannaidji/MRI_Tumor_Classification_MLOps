# 🧠 MRI Tumor Classification & MLOps  

## 🚀 Overview  
This is a **Computer Vision** project for classifying **brain tumors** using MRI scans. The model is based on **Convolutional Neural Networks (CNN)** and integrates MLOps tools for efficient deployment and monitoring.  

## 🛠️ Technologies Used  
- **AI Frameworks:** TensorFlow Keras, Scikit-learn  
- **MLOps Tools:** Docker, DVC, MLflow, GitHub Actions, Grafana, Prometheus, Render  

## 🎓 Project Context  
Final project for the *Attestation of Collegial Studies in Technical Specialization in Artificial Intelligence* at *College de Bois-de-Boulogne*, Montreal, Canada.  

## 🚢 Deployment  
The model is deployed using **Render**.
